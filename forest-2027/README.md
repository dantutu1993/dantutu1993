# 守住你的 2027｜Forest 時間攻防戰（H5 Prototype）

單一檔案的 H5 品牌互動小遊戲。直接用瀏覽器開啟 `index.html` 即可（不需 build、無外部依賴）。

## 遊戲流程
1. **選 2027 目標** → 6 個預設目標 + 自訂（自訂每週時數 3–10h）
2. **目標拆解**：年度 → 每季里程碑 → 每週時數 → 可執行任務（並獲得道具 🎯「明確下一步」）
3. **排行事曆**（週檢視）：預設作息（睡覺／三餐／午休／工作）已鎖定；用筆刷把空格排滿，目標時段需 ≥ 本週目標、≤ 目標 +3h
   - 匯入 Google 日曆：Google 日曆 → 設定 → 匯入與匯出 → 匯出 `.ics`，在遊戲中上傳（依星期對應到 2027 第一週）
   - 「示範匯入」、「自動排目標」、「剩下的填自由時間」三個快捷鍵
4. **時間開始跑**：紅色現在時間線移動；按行事曆進行，隨機觸發突發事件（訊息、滑手機、通知、拖延、熬夜→隔天晚起且效率 -50%、臨時加班），被突發事件覆蓋的時段會被紅色斜紋塊蓋上去
5. **金幣 🪙**：完整專注一段 +2（種下一棵樹 🌳）、正面事件、全天守住、3 連勝。可用來當下抵抗事件，或到 🛒 商店買整週有效的預防道具
6. **結算**：本週專注時數 vs 目標、森林、2027 全年推估、時間小偷排行＋對應 Forest 功能建議 → 下載 Forest / 分享圖卡 / 挑戰連結

## 可調參數（`<script>` 開頭）
- `LINKS`：下載連結
- `GOALS`：目標、每週時數、里程碑、任務
- `ITEMS`：商店道具與價格
- `EV` / `GOOD`：突發／正面事件
- `BASE_RATE`：1x 速度下每秒前進幾分鐘遊戲時間
- `track()`：接上 GA / Pixel 等追蹤事件
